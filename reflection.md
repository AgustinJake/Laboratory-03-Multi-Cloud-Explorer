# Mission Reflection

The Multi-Cloud Explorer laboratory introduced me to three of the most important public cloud providers: AWS, Microsoft Azure, and Google Cloud. The platform that impressed me most was Google Cloud because of its focus on artificial intelligence, machine learning, data analytics, and Kubernetes. I found these technologies interesting because they are becoming increasingly important in modern software development and business.

AWS, Azure, and Google Cloud have many similarities despite having different product names. Each provider offers virtual machines, object storage, databases, networking, identity management, security, monitoring, and container services. They also use geographic infrastructure that allows applications to be deployed in different locations. This means that organizations can achieve scalability and improve the availability of their applications.

Business requirements play an important role in choosing a cloud provider. A company should evaluate its current technology, budget, application requirements, security policies, staff expertise, and future plans before making a decision. For example, Azure is a logical choice for a company that already relies on Microsoft technologies. On the other hand, Google Cloud can be especially useful for an organization whose main focus is AI, machine learning, and data analysis.

Working as a Cloud Solutions Consultant taught me that cloud selection requires more than knowing the names of cloud services. I need to understand what the client is trying to accomplish and then connect those requirements to appropriate cloud technologies. This activity also showed me that different organizations can legitimately choose different providers.

My GitHub portfolio improved because I added several technical documents and organized the information using Markdown. I also learned how to document Linux system information, compare cloud services, create decision matrices, and explain technical recommendations. Overall, this laboratory helped me develop a more practical understanding of how cloud engineers evaluate cloud platforms.
