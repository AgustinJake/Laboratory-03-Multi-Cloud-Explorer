# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a public cloud platform developed by Amazon. It provides organizations with on-demand access to computing, storage, networking, databases, security, analytics, and many other technologies.

AWS allows businesses to use cloud resources without purchasing and maintaining large amounts of physical hardware.

## Global Infrastructure

AWS divides its infrastructure into geographical Regions and Availability Zones. Each Region represents a separate geographic location, while Availability Zones provide isolated infrastructure within a Region.

This design allows organizations to distribute applications across different locations and improve reliability and availability.

## Cloud Management Console

The AWS Management Console is a browser-based interface for controlling AWS resources. Users can create virtual machines, configure storage, manage identities, monitor resources, and access many other AWS services.

## Four Core Services

### Amazon EC2

EC2 provides virtual servers that can run Linux or Windows applications.

### Amazon S3

S3 is an object storage service used for files, backups, images, videos, and other data.

### Amazon VPC

VPC provides a private networking environment where AWS resources can communicate securely.

### Amazon RDS

Amazon RDS is a managed relational database service that supports several popular database engines.

## Three Advantages

1. AWS has a very large selection of cloud services.
2. AWS provides flexible resources that can scale according to demand.
3. AWS has a mature global infrastructure suitable for international applications.

## Typical Enterprise Use Cases

AWS can be used for:

- Online shopping systems
- Enterprise applications
- Backup and disaster recovery
- Website hosting
- Data analytics
- Mobile applications
- Database hosting
- AI and machine learning
