# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a public cloud platform created by Microsoft. It offers services for computing, storage, networking, databases, security, artificial intelligence, application development, and enterprise infrastructure.

Azure is especially useful for organizations that already use Microsoft products.

## Global Infrastructure

Azure provides cloud infrastructure through geographic regions around the world. Many Azure regions include Availability Zones that provide physical separation between infrastructure to improve resilience.

Organizations can choose locations based on performance, availability, compliance, and data residency.

## Cloud Management Console

The Azure Portal is the main web-based management interface for Azure. It allows users to create and manage virtual machines, databases, networks, storage accounts, identities, and other cloud resources.

## Four Core Services

### Azure Virtual Machines

Azure Virtual Machines provide virtual computers that can run Windows or Linux.

### Azure Blob Storage

Blob Storage is designed for storing large amounts of unstructured data such as images, documents, videos, and backups.

### Azure Virtual Network

Azure Virtual Network provides private network connectivity between Azure resources.

### Microsoft Entra ID

Microsoft Entra ID provides identity and access management for users and applications.

## Three Advantages

1. Azure integrates well with Microsoft enterprise products.
2. It provides strong support for hybrid cloud environments.
3. Azure provides many security and compliance features for organizations.

## Typical Enterprise Use Cases

Azure is commonly used for:

- Windows Server migration
- Microsoft application hosting
- Hybrid cloud
- Enterprise databases
- Virtual desktops
- Business applications
- Data analytics
- AI applications
