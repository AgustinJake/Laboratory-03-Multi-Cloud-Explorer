| Category | AWS | Microsoft Azure | Google Cloud |
|---|---|---|---|
| Launch Year | 2006 | 2010 | 2008 |
| Compute Service | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage Service | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking Service | Amazon VPC | Azure Virtual Network | Google Cloud VPC |
| Identity Service | AWS IAM | Microsoft Entra ID | Cloud IAM |
| Primary Strength | Large service ecosystem | Microsoft integration | AI, analytics, and Kubernetes |
| Ideal Organizations | Startups and enterprises | Microsoft-based organizations | Data and AI-focused organizations |

## 1. Which cloud provider offers the broadest range of services?

AWS offers a very extensive collection of cloud products and services. Its portfolio covers infrastructure, databases, storage, networking, security, analytics, serverless computing, AI, and many other areas.

## 2. Which provider best integrates with Microsoft technologies?

Azure is the strongest choice for Microsoft environments. Its services integrate closely with Windows Server, Microsoft 365, Active Directory, SQL Server, and Microsoft Entra ID.

## 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is a particularly strong platform for AI and Kubernetes workloads. Its AI services and Google Kubernetes Engine make it attractive to companies developing machine learning and container-based applications.

## 4. Which cloud platform would you personally choose and why?

I would select Google Cloud because I am interested in data analytics, artificial intelligence, and modern container technologies. Google Cloud provides services that make it possible to develop AI applications while also supporting Kubernetes-based deployments.

## Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | GCP | Managed services can reduce infrastructure administration |
| Enterprise Organization | AWS | Broad services and extensive enterprise capabilities |
| Microsoft Environment | Azure | Native integration with Microsoft's ecosystem |
| AI / Machine Learning | GCP | Strong AI, ML, and data-processing services |
| Kubernetes Deployment | GCP | GKE provides managed Kubernetes |
| Global Web Application | AWS | Strong global infrastructure and scaling capabilities |
