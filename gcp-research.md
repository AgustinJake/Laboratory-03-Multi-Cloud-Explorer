# Google Cloud Platform Research

## Brief Overview

Google Cloud Platform (GCP), also known as Google Cloud, is Google's public cloud computing platform. It provides infrastructure and managed services for computing, storage, networking, databases, analytics, AI, machine learning, and containers.

Google Cloud is particularly well known for its data processing, AI, and Kubernetes technologies.

## Global Infrastructure

Google Cloud uses a worldwide infrastructure organized into Regions and Zones. Multiple zones can exist within a region, allowing workloads to be distributed for improved availability.

Google's private global network also connects many of its cloud locations.

## Cloud Management Console

Google Cloud Console is a browser-based interface for managing cloud projects and resources. It provides access to services such as Compute Engine, Cloud Storage, databases, networking, IAM, and Kubernetes.

## Four Core Services

### Compute Engine

Compute Engine provides virtual machines that can run different operating systems and workloads.

### Cloud Storage

Cloud Storage is an object storage service for files, application data, backups, and media.

### BigQuery

BigQuery is a managed data warehouse and analytics platform designed to process very large datasets.

### Google Kubernetes Engine

GKE is Google's managed Kubernetes service for deploying containerized applications.

## Three Advantages

1. Google Cloud has strong AI and machine learning capabilities.
2. It provides excellent tools for data analytics and large datasets.
3. GKE provides mature support for Kubernetes-based applications.

## Typical Enterprise Use Cases

Google Cloud can be used for:

- Machine learning
- AI research
- Big data
- Data warehousing
- Container applications
- Web applications
- Software development
- Business analytics
